# Health Tracker 🏋️

Full-stack health & fitness tracker with BMI, protein logging, workout plans, diet tracking, and recipes.

## Features
- User authentication (JWT)
- BMI calculator with history charts
- Protein & calorie logging with food database
- Workout plans (Strength / Weight Loss / Endurance) with exercise animations
- Diet plans by goal
- Recipes browser with diet/goal filters
- Dark theme with mobile responsive layout

## Tech Stack
| Layer | Tech |
|-------|------|
| Frontend | React 18 + Vite, CSS Modules |
| Backend | Node.js + Express |
| Database | NeDB (embedded, no setup needed) |
| Auth | JWT + bcrypt |

## Quick Start

**1. Install dependencies**
```bash
npm install          # backend deps
npm run build        # install client deps + build React app
```

**2. Start server**
```bash
npm start            # production (serves built React)
# or
npm run dev          # development (auto-restart on changes)
```

Open **http://localhost:3000**

## Deployment

Set `JWT_SECRET` environment variable in production.
